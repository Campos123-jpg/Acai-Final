# Divino Açaí

Projeto Final: sistema web para uma loja de açaí, com cardápio online, carrinho de compras e painel administrativo.

## Tecnologias
- Front-end: HTML, CSS e JavaScript
- Back-end: Node.js e Express
- Banco de dados: MySQL

## Estrutura
- `frontend/`: páginas, estilos, scripts e imagens do site
- `backend/`: API e conexão com o banco de dados
- `database/`: script SQL para criação do banco

## Desenvolvimento
O projeto será construído por etapas. A configuração local e as instruções de execução serão documentadas conforme a implementação avançar.
